# SignalTruth

**Built on public records. Structured by intelligence.**

SignalTruth is an open-source, AGPL 3.0+ commercial real estate intelligence system designed to unify ownership, market, legal, and public record completeness data into a single confidence-scored property graph.

It reconstructs real estate reality from fragmented public datasets using event-driven architecture, entity resolution, and explainable AI reasoning with full provenance tracking.

---

# 🧱 Core Capabilities

SignalTruth is built around a **modular intelligence graph system** where every property is represented as a living, evolving data structure composed of events, entities, and verified sources.

---

# 🧠 1. Core Property Intelligence Graph
- Unified parcel-based property graph (canonical spatial identity system)
- Temporal event-sourced architecture (append-only state evolution)
- Multi-layer entity graph (properties, people, LLCs, trusts, institutions)
- Lease, deed, lien, permit, valuation, and zoning event modeling
- Cross-property and cross-jurisdiction portfolio linking

---

# 🏢 2. Ownership Intelligence Engine
- Full chain-of-title reconstruction from public records
- Corporate entity resolution (LLC hierarchies, parent-subsidiary graphs)
- Beneficial ownership inference (probabilistic, confidence-scored)
- Shell entity clustering and portfolio discovery
- Cross-jurisdiction ownership mapping
- Real-time ownership change detection from filings

---

# 📊 3. Market Intelligence Module
- Commercial lease and sale comp engine
- Submarket rent trend modeling and forecasting
- Vacancy, absorption, and demand velocity tracking
- Pricing anomaly detection (statistical deviation engine)
- Market cycle reconstruction and segmentation
- Asset class performance benchmarking dashboards

---

# ⚖️ 4. Legal Intelligence Module (Jurisdictional Reasoning Engine)
- Jurisdiction resolver (city → county → state → federal mapping)
- Machine-readable statute and regulation encoding system
- Zoning interpretation engine (use, density, entitlement rules)
- Lease compliance and contract risk analysis
- ADA, EPA, environmental, and building code overlays
- Permit, renovation, and entitlement regulatory analysis
- Legal risk scoring per property/event (non-advisory, interpretive only)
- Regulatory change detection and impact modeling

---

# 📉 5. Public Record Completeness & Omission Detection Engine
- Detects missing or absent sale price / consideration fields in deeds
- Cross-validates transaction data across county, tax assessor, and state records
- Identifies inconsistencies between recorded filings and valuation changes
- Flags partial, redacted, or incomplete municipal reporting
- Generates structured Transaction Completeness Reports
- Completeness scoring per transaction event (0–1 scale)
- Jurisdictional transparency benchmarking across counties/states
- Evidence-linked explanation of missing or conflicting data (no intent inference)

---

# 🧩 6. Event-Driven Intelligence System
- Real-time ingestion of property events (deeds, leases, permits, filings)
- Document-to-structured-event transformation pipeline
- Event-triggered recomputation of ownership, market, and legal states
- Historical event replay engine (time-travel property reconstruction)
- Cross-source conflict detection and resolution flags
- Continuous state evolution tracking per property node

---

# 🔍 7. Entity Resolution & Identity Graph
- Deterministic + probabilistic entity matching engine
- Multi-signal resolution (names, addresses, filings, officers, graph proximity)
- Confidence-weighted entity merging system
- Corporate structure reconstruction engine
- Cross-jurisdiction identity linking system
- Shell entity detection via graph clustering and anomaly patterns

---

# 📡 8. Data Ingestion Layer
- County recorder ingestion pipelines (deeds, mortgages, transfers)
- Tax assessor data integration
- Secretary of State corporate registry ingestion
- Court filings ingestion (liens, judgments, bankruptcies)
- Permit and zoning data ingestion
- Optional MLS/broker feeds (licensed/authorized sources only)
- User-submitted verified data contribution system

---

# 🧮 9. Confidence Scoring System (Universal Trust Layer)
- Global confidence score per output (0–1)
- Multi-factor scoring model:
  - source reliability weighting
  - data freshness decay
  - cross-source agreement strength
  - entity resolution certainty
  - data completeness score integration
- Conflict-aware confidence penalties
- Low-confidence detection thresholds and flags
- Full confidence breakdown transparency per result

---

# 📚 10. Source & Provenance Tracking System
- Every data point linked to original source record
- Full audit trail per property event
- Weighted source reliability system
- Evidence chain graph per output
- Reproducible query engine (same input → identical trace)
- Source lineage visualization per property and entity

- Cross-domain reasoning (ownership + legal + market + completeness)

# 📊 13. Confidence-Backed Output Standard (System-Wide Requirement)
Every system output must include:
- Final confidence score (0–1)
- Confidence breakdown by factor
- Source list with weights and references
- Method trace (step-by-step derivation logic)
- Completeness score (where applicable)
- Explicit uncertainty labeling (no silent assumptions)
