# MindLedger for Real Estate

MindLedger for Real Estate is a **modular, self-hostable real estate operating system** designed to unify CRM, marketing, listings, compliance, analytics, accessibility, and AI automation into a single AGPL-3.0+ platform.

It is powered by a dual-AI architecture (WebGuard + AgentDesk MOLTBOT) and built to support continuous evolution through open-source modules, compliance-aware automation, and agent-controlled customization.

---

# 🧠 System Overview

MindLedger is composed of modular systems that can be added, removed, or replaced without breaking core functionality.

It is designed for:

- Real estate agents and brokerages  
- FSBO / FRBO marketplaces  
- Property marketing platforms  
- Local service ecosystems  
- Compliance-driven housing platforms  

---

# 🤖 Core AI System (MOLTBOT)

## 🌐 WebGuard MOLTBOT (Public / Host-Side)
Handles all public-facing systems:

- Housing listings (MLS + scraped + manual)
- FSBO / FRBO property systems
- Blog and content distribution
- Business directory
- Customer Care Center (CCC)
- Public analytics and listing guidance
- Voice-on-demand accessibility interface

### WebGuard Capabilities
- Natural language Q&A for listings and markets  
- Voice navigation for full accessibility (ADA-first design)  
- Property explanation (pricing, zoning, taxes, flood maps)  
- Compliance enforcement (Fair Housing, FTC, MLS rules)  
- Step-by-step user assistance for transactions  

---

## 🖥️ AgentDesk MOLTBOT (Private / Agent-Side)

Handles operational systems:

- CRM and lead management  
- Marketing automation  
- Social media management (Hootsuite-level module)

- Payroll and accounting integration  
- Analytics and forecasting  
- Listing approval workflows  
- System configuration and module control  

### AgentDesk Capabilities
- Predictive lead scoring  
- Deal forecasting  
- Campaign automation  
- Natural language system control  
- Safe module deployment validation  
- Compliance and legal alerts  
- Business intelligence reporting

- Hourly MLS ingestion  
- Public listing scraping (where legal)  
- FSBO / FRBO listing systems  
- Dynamic property pages:
  - Neighborhood
  - City
  - County
  - ZIP
  - Property type  
- Up to 40 images per listing  
- Document uploads (inspection, survey, HOA, lease, appraisal)  
- 40-year historical sales data (when available)  

## Public Record Data
- Lot & block  
- Legal description  
- Flood maps  
- Zoning classification  
- Tax assessor data  
- Flagging for missing or questionable records  

## Accessibility Property Data
- ADA modifications (ramps, lifts, bathrooms, door widths, elevators)  
- Visual/audio accessibility features  
- Verified documentation upload  
- Accessibility compliance tagging
